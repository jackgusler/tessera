# Tessera

A **grid tile-placement synergy roguelike** (in the spirit of Balatro / Nubby's Number Factory / Ballionaire / CloverPit).

Each round you draw a few 16×16 tiles and place them on a board; adjacency and pattern
synergies chain into a score. Beat the round's escalating quota, shop between rounds to draft
new tile types and modifiers, and lose the run when you miss a quota (permadeath).

- **Engine:** Godot 4.6.3
- **View:** top-down, 16×16 tiles, TileMap-based, flat pixel art
- **Status:** scaffold — core systems and most conventions are still open decision tickets (Jira project `TES`)

## Running

Open the folder in Godot 4.6.3, or headless:

```
Godot_v4.6.3-stable_win64.exe --path . --headless
```
